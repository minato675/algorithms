# Algorithms

Python 알고리즘 풀이와 기초 학습 기록을 모은 저장소입니다.
기존 네 저장소의 코드, 풀이 버전, 커밋 이력을 함께 보존했습니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| [A-_-](A-_-/) | 알고리즘 풀이와 풀이 버전 기록 |
| [B-](B-/) | 24703번 풀이와 스켈레톤 코드 |
| [TIL](TIL/) | 백준 풀이와 Python 기초 연습 |
| [swea](swea/) | SWEA 문제별 풀이와 문제 자료 |

기존 폴더 구조와 파일 내용을 그대로 옮겼습니다. 중복 풀이, 빈 파일,
학습 중간 버전도 원본 기록의 일부로 보존되어 있습니다.
각 파일의 정답 여부나 실행 환경은 개별 풀이에 따라 다릅니다.

## 커밋 이력

- 원본 커밋 ID, 작성자, 작성 시각과 메시지를 유지한 채 `main`에 병합했습니다.
- 각 저장소의 원래 브랜치는 `history/<원본 저장소>/<브랜치>`에서도 확인할 수 있습니다.
- 원래 경로로 과거 풀이를 살펴보려면 해당 `history` 브랜치를 선택하세요.
- 통합 시점의 원본 커밋과 검증 기준은 [통합 기록](MIGRATION.md)에 정리했습니다.

이 저장소에서 이후 알고리즘 풀이와 학습 기록을 이어갑니다.
